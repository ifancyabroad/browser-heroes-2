# SkillsIcons visual index

Static snapshot of all 3353 PNGs in the SkillsIcons library, including background variants. Unity .meta files are excluded.

Open the sheets as images, then inspect shortlisted originals at full size. Labels are snapshot IDs; manifest.json maps each ID to its source path, SHA-256, dimensions, sheet, row, and column. Paths are relative to libraryRoot in the manifest; substitute another root if the library moves. Row and column numbers start at 1.

Review all collections visually rather than limiting discovery to filenames. Transparent images are shown on a dark grey background. Sheets do not record game usage: check the current repository for exact and visually similar duplicates before selecting an icon. The library is assumed fixed; regeneration is unnecessary for normal skill creation.
